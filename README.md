# Professional Portfolio

This project is a personal portfolio website developed using modern web technologies to showcase projects and skills in a professional and engaging way.

## Technologies Used
- **React.js**: A JavaScript library for building user interfaces.
- **Vite**: Next-generation frontend tooling.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **TypeScript**: Strongly typed programming language that builds on JavaScript.

## Features
- Fully responsive design that works seamlessly across all devices and screen sizes.
- Modern User Interface (UI) with a high-quality User Experience (UX).
- Dedicated sections for showcasing projects, skills, and personal information.
- High performance thanks to modern build tools.

## How to Run
1. Install project dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build the project for production:
   ```bash
   npm run build
   ```

# معرض الأعمال الاحترافي (Professional Portfolio)

هذا المشروع عبارة عن موقع شخصي (بورتفوليو) تم تطويره باستخدام أحدث تقنيات الويب لعرض الأعمال والمهارات بطريقة احترافية وجذابة.

## التقنيات المستخدمة
- **React.js**: مكتبة بناء واجهات المستخدم.
- **Vite**: أداة بناء وتطوير سريعة.
- **Tailwind CSS**: إطار عمل لتصميم واجهات عصرية ومتجاوبة.
- **TypeScript**: لضمان كتابة كود نظيف وخالٍ من الأخطاء.

## المميزات
- تصميم متجاوب يعمل بكفاءة على جميع الشاشات والأجهزة.
- واجهة مستخدم (UI) عصرية مع تجربة مستخدم (UX) ممتازة.
- أقسام مخصصة لعرض الأعمال، المهارات، ومعلومات عن المصمم.
- أداء سريع ومثالي بفضل تقنيات البناء الحديثة.

## كيفية التشغيل
1. قم بتثبيت الحزم البرمجية:
   ```bash
   npm install
   ```
2. تشغيل المشروع محلياً للبدء بالتطوير:
   ```bash
   npm run dev
   ```
3. بناء المشروع لبيئة الإنتاج:
   ```bash
   npm run build
   ```

# Profesyonel Portfolyo

Bu proje, çalışmaları ve becerileri profesyonel ve etkileyici bir şekilde sergilemek için en modern web teknolojileri kullanılarak geliştirilmiş kişisel bir portfolyo web sitesidir.

## Kullanılan Teknolojiler
- **React.js**: Kullanıcı arayüzleri oluşturmak için JavaScript kütüphanesi.
- **Vite**: Yeni nesil frontend geliştirme aracı.
- **Tailwind CSS**: Hızlı ve modern web tasarımları için utility-first CSS framework'ü.
- **TypeScript**: Hataları aza indirmek ve temiz kod yazmak için statik tipli dil.

## Özellikler
- Tüm cihazlarda ve ekran boyutlarında sorunsuz çalışan duyarlı (responsive) tasarım.
- Yüksek kaliteli kullanıcı deneyimi (UX) sunan modern kullanıcı arayüzü (UI).
- Projeleri, yetenekleri ve kişisel bilgileri sergilemek için özel olarak tasarlanmış bölümler.
- Modern derleme araçları sayesinde yüksek performans.

## Nasıl Çalıştırılır
1. Proje bağımlılıklarını yükleyin:
   ```bash
   npm install
   ```
2. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
3. Canlıya almak için projeyi derleyin (Build):
   ```bash
   npm run build
   ```
